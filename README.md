# volmedo.com

Personal website of Vicente Olmedo, served by GitHub Pages at <https://www.volmedo.com>.

The site is plain, hand-written HTML and CSS: no build step, no JavaScript and no third-party requests.
`.nojekyll` tells GitHub Pages to serve the files as they are.

- `index.html`, `404.html`: the pages.
- `assets/site.css`: shared styles.
- `assets/fonts/`: self-hosted [Nunito](https://github.com/googlefonts/nunito) (SIL Open Font License, see `OFL.txt`).
- `img/`: images.

The visual design is based on the [Galada](https://github.com/artemsheludko/galada) Jekyll theme by Artem Sheludko (MIT, see `LICENSE.txt`).
Icons are from [Ionicons](https://ionic.io/ionicons) (MIT).
